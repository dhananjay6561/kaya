# Contributing

1. Fork the repo and create a branch from `main`.
2. Keep each pull request to one small, focused change.
3. Run `npm run lint`, `npm run typecheck` and `npm run build` before pushing.
4. Sign off every commit (`git commit -s`), which certifies you wrote it or have the right to submit
   it under the MIT license.
5. Never commit `.env`, keys, WhatsApp session files, browser profiles or real chat data. Use made-up
   data in tests.

`main` only accepts pull requests, and history stays linear (rebase merges only).

Found a security problem? Follow [SECURITY.md](SECURITY.md) instead of opening an issue.
