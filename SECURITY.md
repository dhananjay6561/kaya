# Security policy

Kaya reads private chats and acts on logged-in accounts, so security reports are taken seriously.

## Reporting a vulnerability

Please report privately through
[GitHub's private vulnerability reporting](https://github.com/dhananjay6561/kaya/security/advisories/new).
Don't open a public issue for security problems.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a
reply within 7 days.

## Supported versions

Only the latest commit on `main` gets fixes.

## Never share

Don't paste API keys, `.env` contents, WhatsApp session files, browser profiles or chat data in
issues, pull requests or reports. If one leaks, rotate it right away.
